# BigCase 참조법령 기준 파싱 규칙

## 목적
- BigCase / 법제처 / LBox에서 수집한 판례·행정해석을 `참조법령` 중심으로 1차 분류한다.
- 기존 키워드/카테고리 기반 분류를 버리는 것이 아니라, **참조법령을 상위 앵커**로 두고 세부 카테고리를 그 아래에 매핑한다.
- 내부 서비스에서 노동법 사건을 안정적으로 걸러내고, 상세 페이지에서 "어떤 법 체계의 사건인지"를 먼저 보여주기 위한 기준이다.

## BigCase 기준 핵심 법령군
`evaluation/bigcase_bulk/court_decisions_ready.jsonl`에서 제목/요약/카테고리 기준으로 확인했을 때, 현재 BigCase 축에서 가장 자주 엮이는 법령군은 아래와 같다.

### Tier 1: 노동 핵심법
- `근로기준법`
- `근로자퇴직급여보장법`
- `남녀고용평등과 일·가정 양립 지원에 관한 법률`
- `산업재해보상보험법`
- `노동조합 및 노동관계조정법`
- `기간제 및 단시간근로자 보호 등에 관한 법률`
- `최저임금법`
- `산업안전보건법`

### Tier 2: 고용관계 확장법
- `고용보험법`
- `파견근로자보호 등에 관한 법률`
- `고용상 연령차별금지 및 고령자고용촉진에 관한 법률`
- `직업안정법`
- `외국인근로자의 고용 등에 관한 법률`
- `임금채권보장법`
- `근로자참여 및 협력증진에 관한 법률`

### 약칭/별칭 매핑
- `남녀고용평등법` -> `남녀고용평등과 일·가정 양립 지원에 관한 법률`
- `근로자퇴직급여 보장법` -> `근로자퇴직급여보장법`
- `노동조합법`, `노조법` -> `노동조합 및 노동관계조정법`
- `기간제법` -> `기간제 및 단시간근로자 보호 등에 관한 법률`
- `파견근로자보호법` -> `파견근로자보호 등에 관한 법률`

- `근로기준법` 아래에서 해고/징계/무단결근/전보/저성과/수습 등 세부 이슈를 다시 나눠야 한다.

## 1차 파싱 규칙
### 규칙 A: 참조법령이 있으면 참조법령 우선
1. 본문/메타에서 `참조법령`, `관련 법령`, `법령의 적용`, `적용 법조`, `판시사항 관련 법령` 블록을 찾는다.
2. 해당 블록에서 위 법령군과 매칭되는 법명을 우선 추출한다.
3. 추출된 법령이 1개 이상이면 `reference_laws` 배열에 저장한다.

### 규칙 B: 참조법령이 없으면 본문 법명 탐지
1. `주문`, `이유`, `법령의 적용`, `질의`, `회시`, `판단` 본문에서 법명을 탐지한다.
2. 약칭은 위 `약칭/별칭 매핑`으로 정규화한다.
3. 중복은 제거하고 최초 출현 순서를 유지한다.

### 규칙 C: 노동법 판정
아래 중 하나라도 만족하면 `is_labor_law = true`
- `reference_laws`에 Tier 1/Tier 2 법령이 존재
- 제목/사건명/질의요지에 `부당해고`, `직장내괴롭힘`, `징계`, `임금체불`, `퇴직금`, `갱신기대권`, `정리해고`, `전보`, `노동조합`, `산재`, `최저임금`이 존재

## 2차 세부 카테고리 규칙
### 근로기준법 축
- `해고`, `부당해고`, `해고무효`, `해고회피노력` -> `dismissal`
- `징계`, `징계해고`, `징계양정`, `비위` -> `discipline`
- `무단결근`, `결근`, `출근불량` -> `absence`
- `수습`, `시용`, `본채용거부` -> `probation`
- `저성과`, `업무능력 부족`, `평가하위` -> `performance`
- `전보`, `인사이동`, `전직` -> `transfer`
- `정리해고`, `긴박한 경영상 필요`, `구조조정` -> `redundancy`
- `사직 강요`, `사직서`, `의사표시 하자` -> `forced_resignation`
- `임금`, `체불임금`, `연장근로수당`, `휴일근로수당` -> `wages`

### 남녀고용평등법 축
- `직장내 성희롱`, `성희롱`, `2차 가해` -> `sexual_harassment`
- `괴롭힘`, `직장내괴롭힘`, `신고 보복`, `불이익 처우` -> `workplace_harassment`
- `육아휴직`, `출산휴가`, `모성보호` -> `family_leave`

### 근로자퇴직급여보장법 축
- `퇴직금`, `중간정산`, `퇴직연금`, `중간정산 사유` -> `retirement_pay`

### 기간제법 / 파견법 축
- `기간만료`, `계약만료`, `갱신기대권` -> `fixed_term`
- `파견`, `불법파견`, `사용사업주` -> `dispatch`

### 노조법 축
- `단체교섭`, `부당노동행위`, `노동조합`, `사용자성`, `쟁의행위` -> `labor_union`

### 산재 / 안전 축
- `산재`, `업무상 재해`, `출퇴근 재해` -> `workers_compensation`
- `산업안전보건`, `안전조치`, `중대재해` -> `industrial_safety`

## 현재 BigCase 카테고리와의 연결
현재 BigCase 수집 카테고리는 아래처럼 참조법령 앵커에 우선 매핑한다.

| 현재 카테고리 | 우선 법령 앵커 | 세부 이슈 |
| --- | --- | --- |
| Q1_무단결근 | 근로기준법 | absence |
| Q2_결근절차 | 근로기준법 | absence / discipline |
| Q3_괴롭힘성립 | 남녀고용평등법 | workplace_harassment |
| Q4_괴롭힘보복 | 남녀고용평등법 | workplace_harassment |
| Q5_수습해고 | 근로기준법 | probation |
| Q6_수습절차 | 근로기준법 | probation |
| Q7_저성과 | 근로기준법 | performance |
| Q8_징계양정 | 근로기준법 | discipline |
| contract_expiry | 기간제법 | fixed_term |
| embezzlement | 근로기준법 | discipline |
| misconduct | 근로기준법 | discipline |
| no_dismissal | 근로기준법 | forced_resignation / dismissal |
| redundancy | 근로기준법 | redundancy |
| sexual_harassment | 남녀고용평등법 | sexual_harassment |
| transfer | 근로기준법 | transfer |
| violence | 근로기준법 | discipline |

## 저장 필드 권장
정제 파이프라인에서 아래 필드를 추가하는 것을 권장한다.
- `reference_laws`: 정규화된 법령명 배열
- `primary_law`: 대표 법령 1개
- `secondary_laws`: 나머지 법령 배열
- `issue_bucket`: 세부 쟁점 (`discipline`, `absence`, `probation`, ...)
- `is_labor_law`: 노동법 사건 여부

## 운영 원칙
- `참조법령 -> 대표 법령 -> 세부 이슈` 순으로 분류한다.
- 법령명이 불명확해도 현재 `category`, `title`, `summary_short`, `key_issue`는 fallback으로 유지한다.
- 상세 페이지에서는 법령 앵커를 상단 메타로 먼저 보여주고, 세부 이슈는 그 아래에 노출한다.
